# Express Backend API (JavaScript)

This project is a simple CRUD API built using Node.js and Express.  
It is designed for learning backend fundamentals and understanding how REST APIs work.

---

## Features

- Create, Read, Update, Delete (CRUD) operations  
- Built with Express.js  
- Uses in-memory (dummy) data instead of a database  
- Fast development using Nodemon  

---

## Tech Stack

- Node.js  
- Express.js  
- Nodemon
